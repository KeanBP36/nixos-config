5. Clashes to know about
File tree: Ctrl+k shows file info there instead of moving up. Shift+h toggles dotfiles and Tab previews. Click into a code window before using your window and tab keys.
gr delay: your gr map (references) makes Neovim pause briefly when you type gr, because it’s also the start of grn, gra and grr.
Tab delay: Tab waits for the next key, so Vim’s own Ctrl+i jump-forward is delayed. Ctrl+o (jump back) is unaffected.
Snippets: your Tab override means Tab no longer jumps between snippet fields. Gitsigns also has no hunk keys set.
Terminals: some terminals treat Ctrl+h as Backspace, which would break the window move.
